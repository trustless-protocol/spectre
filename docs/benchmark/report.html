Proof generation

Wall-clock time to generate one Groth16 proof for an N-signer quorum batch, on the GPU (ICICLE / CUDA) backend. Witness build and local verification are sub-10 ms at every bucket, so the figures below are effectively the prove step.

N = quorum signers, not validator count. A bucket is sized by the number of highest-voting-power validators needed to cross 2/3 of total power — not the chain's total validator count. Voting power is usually concentrated in the top validators, so even a 180-validator chain often reaches quorum with ~14–16 signers (bucket N = 16). Proof-generation time depends only on the bucket, so it is independent of how many validators the chain has.
